# 首页情节火花

## 目标

给作者一个轻量的本地构思辅助：从一组原创冲突钩子中抽取建议、可以重抽，并且只有作者明确选择后才写入故事想法。它不请求模型，不覆盖已有草稿，也不新增持久化表。

## 实施

- [x] 补首页组件测试，确认火花可抽取、重抽不重复，加入前不改变想法，加入后进入自动保存草稿。
- [x] 在首页表单加入“情节火花”内联操作，使用既有工作台控件、色彩 token 与图标。
- [x] 抽取时显示一次简短紫色亮起反馈；光斑与聚焦光晕统一使用现有 action token，避免青绿色旧色和紫色主色打架。
- [x] 适配窄屏布局并保留键盘操作、可见焦点与屏幕阅读器播报。
- [x] 更新 README 与产品能力说明。
