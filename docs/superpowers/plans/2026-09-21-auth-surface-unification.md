# 登录注册与作者表面统一记录

日期：2026-09-21

## 目标

把登录、注册、桌面激活、首页、模型设置、工作流、数据管理、命令面板和生产期作者抽屉收束为同一套小奕工作台语言：近黑画布、紫色主操作、细边框、8px 控件圆角、清晰状态反馈和可见键盘焦点。只调整前端交互与视觉层，不改 API、数据库、IPC、候选采纳或 revision 契约。

## 源码审查范围

- `AuthGate` / `ActivationGate`：登录、注册、邀请码、密码强度、错误与限流反馈；
- `workbench-refresh.css` 最终主题层：弹窗、命令面板、导航抽屉和各类作者抽屉的历史覆盖；
- 数据管理、Provider、工作流、时间线、资料卡、分支、搜索替换、资产库、创作中枢和生产任务面板的表面状态；
- 现有单测、主流程 E2E、邀请码注册 E2E 和响应式门禁。

## 落地内容

- 登录/注册切换改成语义清晰的“登录 / 注册”双标签，邀请码要求、密码强度和本地优先说明继续保留在表单上下文中；
- 登录与注册继续共用一张认证面板：桌面/平板限制面板高度并让表单内部可滚动，小屏切回页面自然滚动，避免注册字段把登录布局撑成另一套界面；
- 登录、注册和桌面激活共用同一套 rail/card 结构、紫色 focus ring、暗色输入、错误/限流状态和移动端单列布局；
- Provider、工作流、数据管理和命令面板统一 modal surface、标题栏、按钮、输入、select、成功/失败状态与 reduced-motion 行为；
- 记忆中心、故事资料卡、时间线、分支、全局搜索、资产库、创作中枢、一致性检查和生产任务中心统一 drawer surface、卡片、输入控件、状态色与移动端宽度；
- 保留首页近黑画布、紫色主色、作者工作台信息架构和既有抽屉导航，不复制任何外站源码、资源、品牌视觉或文案；
- 维持所有主要交互的键盘焦点可见性，抽屉/弹窗不会依赖 hover 才能发现，`prefers-reduced-motion` 下关闭装饰性动画与过渡。

## 浏览器验收

- 已在本地浏览器打开首页导航、模型设置、登录和注册界面确认视觉统一；
- 响应式门禁覆盖 `1440x960`、`1024x768`、`390x844`，检查页面级横向宽度、移动端单列和抽屉不重叠；
- 邀请码注册流程使用真实 HTTP API 验证注册页文案和表单行为；
- 本地开发服务若已有进程占用 `5173`，复用现有服务查看界面，不修改后端契约。
