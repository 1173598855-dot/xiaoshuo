# v0.2 可控生成与记忆审阅升级

## 目标

在 v0.1.0 长篇记忆中心的基础上，让作者能够在正文落盘前审阅记忆变化、查看完整历史并回滚，同时提升生成失败后的可恢复性，并把测试与 Windows 安装包发布纳入 GitHub Actions。

## 边界

- 继续保持候选先审后采纳；记忆变化只能在 accept 事务中写入正式账本。
- 记忆历史必须包含可恢复正式状态的完整字段；回滚本身生成新的手动修正 revision，不删除历史。
- 取消、暂停和重试必须可中断，不得把 Provider 凭据写入日志、候选或 Action 输出。
- 首版不引入向量数据库、云端记忆同步或多用户权限。
