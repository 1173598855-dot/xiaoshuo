## 公开页面审查

审查对象：

- [Vibe Hub 首页](https://vibe-hub.org/en)
- [Vibe Hub Drawer 组件说明](https://vibe-hub.org/en/drawer)

页面可访问，使用公开页面、浏览器 snapshot、点击和 390×844 / 1280×900 视口检查完成审查。没有下载、复制或引用其源码、资源与品牌视觉。

### 可复用的交互模式

1. 抽屉：保持后方列表和滚动上下文可见；抽屉自身提供清晰标题、关闭入口、内容区和动作区。页面同时解释了右侧详情、左侧导航、移动端底部动作三种方向，并明确不在抽屉内再嵌抽屉。
2. 快捷操作：顶部搜索、分类切换、前后条目切换、收藏和复制 Markdown 都是短路径动作；搜索提供清除入口，收藏在点击后切换为“移除收藏”，复制后给出“Copied”反馈。
3. 状态反馈：收藏使用 `pressed` 状态，复制使用按钮内状态变化和 `alert`，页面通过 breadcrumb、上一条/下一条和当前分类保持位置感。
4. 小组件模式：条目卡片、分类按钮、状态/徽标、抽屉 shell、面包屑和推荐工具区都是可复用的单职责单元；页面没有把所有动作都升级成模态框。
5. 响应式与可达性：移动视口仍保留主要导航、搜索和条目操作；公开页面提供了 focus、reduced-motion、overflow 等相关术语入口，提示这些状态应被显式验证。

## 本地转译

保持小奕现有近黑画布、紫色主色、作者工作台信息架构和“候选先审后采纳”语义，具体落地为：

- `WorkbenchNavigationDrawer`：跨首页、方向选择、生产室、正式正文的左侧导航抽屉；支持 `Escape`、Tab 循环、关闭后焦点回收、当前作品状态和上下文工具入口。
- `WorkbenchQuickActions`：统一顶栏的导航、常用动作、更多菜单和 `Ctrl/Cmd + K` 入口；保留原有“模型设置”“工作流”“快速操作”语义。
- `WorkbenchStatusStrip`：在首页、方向、生产和正文页面显示本地保存、候选审核、生成状态、章节进度、记忆上下文和导出状态；生产状态使用 `aria-live`。
- `WorkspaceLayout` 紧凑布局：平板/移动端不再把两侧控制栏堆到正文前后，而是用可关闭的章节/上下文抽屉；从移动视口回到桌面会恢复此前侧栏偏好。

### 交互边界

- 没有新增网络请求、共享契约字段、数据库写入、IPC channel 或生成/采纳流程。
- 资产库在首页沿用当前浏览器草稿；从作品页打开时仍通过既有本地草稿入口带回素材。
- Vibe Hub 的文案、颜色、图形、布局数值和源码均未复制；这里只采用通用交互语义，并以小奕既有 tokens、lucide 图标和中文作者词汇重做。
