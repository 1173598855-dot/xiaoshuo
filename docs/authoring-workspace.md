# 创作中枢与批量工作流

“创作中枢”是作品内的作者资料库，保存场景卡、伏笔生命周期、作者笔记、每日目标、术语规范、人物知识边界、系列档案、Prompt 版本和生产配方。它通过 `authoring_workspaces` 独立表保存，拥有自己的 revision，不会改变正文 revision；每次 PATCH 都必须携带 `expectedRevision`。

## 统一作者路径

1. 在生产室打开“创作中枢”，先看作品健康度和当前生成上下文。
2. 在“作者资料”补齐场景、伏笔、人物知识边界和术语锁定。
3. 使用生产配方保存常用记忆选择；生成上下文检查器会展示本次实际注入的条目及选择模式。
4. 在“全局搜索”中先检索，再按范围执行全文批量替换。批量替换只接受当前作品 revision，成功后正文章节各自增加一次 revision，作品 revision 只增加一次。
5. 在正式正文页导入 Markdown/TXT/DOCX，或导出 Markdown/TXT/DOCX/ePub；“打印 / PDF”使用当前排版样式打开系统打印流程。

## 安全与恢复

- 锁定章节不会被批量替换或导入覆盖；
- 导入和替换都在 SQLite 事务内执行，章节旧内容进入 `chapter_revisions`；
- 工作区保存遇到 revision 冲突时只返回冲突，不合并覆盖另一窗口的资料；
- 批量替换先执行只读预检，显示命中数量与涉及范围，作者确认后才写入；
- Prompt、系列档案和生产配方只保存文本与无密钥配置，不能进入 Provider 凭据库；
- 每次 draft/review/repair 都携带冻结的作者规则上下文；工作区 revision、术语、知识边界、启用 Prompt 或匹配配方变化后，旧候选不可采纳；
- ePub 包为本地生成的无依赖 ZIP，`mimetype` 位于首个未压缩条目，适合导入常见阅读器。
