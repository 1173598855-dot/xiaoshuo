# 小奕小说生成工具 v0.5.0

发布日期：2026-09-25

## 本版更新

- 新建故事改为独立小说创作页：扩大构思输入区，加入落笔提示；首页只保留最近作品和清楚的新建入口。
- 本地草稿在切页时立即保存，重新进入创作页可继续写；保留预设、情节火花、资产带入、方向数量、模型与工作流设置。
- 工作台页面按首页、创作、方向、生产、正文明确分层；工作区导航、快捷操作和命令面板都可直接进入创作页。
- 收敛 AppShell、HTTP 路由和桌面 IPC 的页面/边界组织，统一光效与减少动态效果策略。
- 加固桌面退出保护、Provider 生成清理、用量结算事务、启动恢复读取和数据库导出 sidecar 检查。
