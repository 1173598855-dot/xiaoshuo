### 本轮审查结论与范围

- 当前项目已经具备工作区、命令面板、章节树、专注模式、资料卡、记忆中心、时间线、候选审核和多格式导出，暂不新增大型模块。
- 发现的明确问题是命令面板触控关闭和快捷键辅助技术语义不足；本轮只修这两个前端交互点。
- 改动范围限定为 `src/client`、对应前端测试和本开发记录，不改 API、数据库、IPC、生成状态或 revision 契约。
- 验收命令：`npm run lint`、`npm run typecheck`、`npm run test:run`、`npm run build`、`npm run e2e`、`git diff --check`。

## 深度交互开发记录（2026-09-21）

- 章节工作区借鉴 outliner / corkboard 类工具的“先筛选、再定位、再阅读”路径：增加本地章节筛选和当前章前后导航，不新增后端数据。
- 工作区借鉴桌面写作工具的布局记忆：在当前浏览器会话保存侧栏开关、宽度和专注模式选择，刷新后恢复。
- 命令面板继续收紧为跨设备入口：触控指针关闭、快捷键语义和焦点恢复保持一致。

## 前端收紧开发记录（2026-09-21）

- 删除未被任何入口引用的 `AuthoringDock` 实验组件及其样式；清理旧 `book-card`、`book-grid`、`library-count` 和 `production-top-actions` 样式。
- 首页新增“想法 → 方向 → 生产 → 审核”的写作路径提示，统一书架、三栏工作区与错误状态的视觉层级。
- 将颜色角色收敛为 `surface / text / border / action / state` 语义 token，旧短名和 `atlas-*` 保留为兼容别名。
- 移除黑洞背景的全局指针监听、RAF 和呼吸动画，保留静态氛围图层；删除无状态表达的首页漂移线动画。
- lint、typecheck、90 个测试文件 / 378 项测试、build + smoke、5 条响应式 E2E 和 `git diff --check` 全部通过。

## 企业内网 P0 基线

本版本把项目定位为**单用户 / 单租户、本地优先的企业内网小说工作台**，不引入多人协作、多租户、实时编辑或云端协作。

- 增加生产环境访问令牌、来源白名单、请求 ID 和滑动窗口限流；
- 增加 `/api/health`、`/api/ready`、Prometheus 指标和受保护的运维视图；
- 增加持久化生产队列、并发上限、暂停/恢复、取消和进程重启恢复；
- 增加 Provider 用量、月度 Token/预算限制、成本估算和显式故障转移；
- 增加结构化日志、审计事件和失败告警，并确保密钥、提示词不进入日志或 SQLite；
- 增加 SQLite 原子备份、完整性校验、可选 NAS/网络盘副本，以及安全恢复脚本；
- 增加 Docker 部署文件、依赖安全扫描和升级/回滚运行说明；
- 浏览器端支持当前会话访问令牌；桌面端继续使用 Main-only 的安全凭据库；
- 兼容 v0.3.1 数据库，首次启动时自动补齐运维表。

## 升级与回滚

升级前先执行一次已验证备份；迁移失败不会用未验证数据库替换活动数据库。详细的环境变量、探针、备份恢复和回滚步骤见 [`docs/operations/enterprise-p0.md`](../operations/enterprise-p0.md)。
