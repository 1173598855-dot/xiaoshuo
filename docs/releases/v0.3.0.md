# v0.3.0

## 可控上下文与候选编辑

- 记忆中心新增“自动推荐 / 仅发送选中”模式，可逐条控制哪些本地记忆进入当前 Provider；空选择不会发送记忆。
- 记忆选择冻结在 production run 和 candidate，参与上下文 hash，生产恢复和 accept 会重新校验。
- 候选正文支持在正式采纳前手动编辑，使用 candidate text revision 乐观锁；编辑后旧审核和记忆提议失效，必须重新审核。
- 章节审核新增初始候选与当前候选的逐行 Diff，保留候选隔离和正文 revision 安全边界。
- 新增对应 HTTP API、Electron 白名单 IPC、SQLite 迁移、契约/服务/UI 回归测试。
