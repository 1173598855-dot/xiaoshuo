# v0.4.0 开放式故事创作与模型工作流

## 本次开发

- 故事方向数量由作者配置，支持 1–12 个，默认 3 个；方向数量写入作品并贯穿导演提示、持久化和候选校验。
- 新增单模型和多模型协作两种工作流，可为规划导演、章节写作、内容审核、问题修复角色指定不同模型。
- 服务端按角色路由模型，生产 run 只保存不含密钥的 workflow descriptor；候选仍需审核后才能原子采纳。
- 浏览器工作流仅保存在当前标签页 sessionStorage；桌面工作流通过白名单 IPC 保存无密钥选择，由 Main/Vault 解析凭据。
- 桌面端协作角色必须使用当前已保存的同一 Provider，可分别选择不同模型，避免跨 Provider 误复用 API Key。
- 保留作品 revision 冲突保护、generation/context 冻结、Renderer 无 Node 能力和公开错误归一化边界。
