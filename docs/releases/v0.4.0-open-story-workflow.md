# v0.4.0 开放式故事创作与模型工作流

## 本次开发

- 故事方向数量由作者配置，支持 1–12 个，默认 3 个；方向数量写入作品并贯穿导演提示、持久化和候选校验。
- 新增单模型和多模型协作两种工作流，可为规划导演、章节写作、内容审核、问题修复角色指定不同模型。
- 服务端按角色路由模型，生产 run 只保存不含密钥的 workflow descriptor；候选仍需审核后才能原子采纳。
- 浏览器工作流仅保存在当前标签页 sessionStorage；桌面工作流通过白名单 IPC 保存无密钥选择，由 Main/Vault 解析凭据。
- 桌面端跨 Provider 协作使用每个 Provider 已保存的独立 credentialId；无密钥固定地址 Provider 可直接参与，Renderer 不会收到任何已保存 API Key。
- 启动恢复先读取可恢复作品 ID，再按需读取作品详情，避免对全部作品执行 N+1 扫描。
- 保留作品 revision 冲突保护、generation/context 冻结、Renderer 无 Node 能力和公开错误归一化边界。

## Xiaoyi Studio 前端升级

- 首页、方向画廊和生产室改为浅色空间层次，白色实体面板承载正文与候选，液态玻璃仅用于导航、抽屉和临时操作层。
- 方向卡片聚焦后按键盘 `Space` Peek 预览，预览中可以直接选择候选；`Ctrl/Cmd + K` 打开按当前页面过滤的命令面板。
- 生产进度使用 transform 动画，按钮、焦点、状态和章节记录均提供清晰反馈；移动端采用单列布局和底部 sheet，适配 `390x844`。
- 账号入口改为登录/邀请码注册双态工作台，增加字段级校验、密码可见性、强度反馈、提交中/成功/错误状态，并在移动端折叠为单列。
- 修复方向卡片 Space 冒泡、命令面板焦点陷阱与快捷键执行、候选审核稳定锚点；将视觉 token 收敛到基础层并降低非必要全屏 blur。
- 认证失败支持 429 Retry-After 倒计时与 session 过期恢复；首页草稿自动保存、作品阶段标签和自定义预设；候选记忆支持批量审阅与 Diff 折叠。
- 生产室显示持久队列的重试次数、下次尝试时间、错误原因和最近心跳；候选历史支持只读预览与安全恢复；首页新增本地创作资产库。
- 生产室资产库可从当前作品提取故事起点、人物组、世界与地点、文风和章节结构；一致性问题可直接跳回资料卡、时间线或全局搜索。
- 资产库支持多选素材组合成新的可编辑模板，继续复用人物与世界设定。
- 作者端新增生产任务中心，可按作品查看任务历史、重试次数和状态，并从历史任务恢复当前生产上下文；Web/桌面共用无密钥队列投影。
- 新增动效遵循 `prefers-reduced-motion`，未改变 API、IPC、凭据、revision 或 generation/context 冻结边界。

## 审查修复

- 生产 Worker 使用 `enqueueWorkflow` 在唤醒前绑定完整工作流，消除 writer fallback 竞态。
- 删除错误解析无密钥 descriptor 的旧辅助函数。
- 启动恢复通过单次详情投影请求获取可恢复作品，保留旧 ID 接口作兼容回退。
- 桌面 Vault 保存每个 Provider 的无密钥 profile 与独立 credentialId；跨 Provider 工作流按角色解析对应凭据，清除任一被引用凭据时会清理工作流选择。
