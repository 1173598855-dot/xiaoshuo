# v0.2.0

## 可控生成与记忆审阅

- 章节审核新增 memoryDelta 审阅：新增、更新、解决均可逐条采纳或忽略；未确认的变化不会进入正文或记忆账本。
- 记忆 revision 保存完整快照，记忆中心支持查看历史并回滚；回滚会生成新的 `manual_edit` revision，不删除历史。
- 记忆注入预览显示当前章节实际注入的条目及选择原因。
- Provider 遇到限流或上游暂不可用时执行最多两次退避重试，退避过程可被暂停、停止或取消中断。
- 新增 HTTP API 和 Electron 白名单 IPC 通道，保持 Main-only Provider Vault 与 Renderer 隔离。
- 新增 GitHub Actions 质量门禁和 Windows NSIS 安装包发布流程。
